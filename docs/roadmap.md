# Roadmap

This roadmap reflects the current ForkFlow implementation and nearby improvements only.

## Current Production Surface

- Dashboard
- Restaurant resolution
- Menu management
- Floors and tables
- Reservations
- Kitchen board
- Orders
- Analytics
- QR ordering
- Customer menu
- Customer order tracking

## Future Improvements

- Add automated tests for route handlers and domain services.
- Add stronger optimistic UI and retry handling for kitchen status changes.
- Add export options for analytics reports.
- Add richer table-layout editing controls.
- Add role-specific access checks for manager, staff, and kitchen users.
- Add production observability for route errors and latency.
